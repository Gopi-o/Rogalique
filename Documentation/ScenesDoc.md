# Система сцен

## Обзор
Сцены представляют собой основные состояния игры (меню, игровой уровень, пауза и т.д.). Каждая сцена управляет своим набором игровых объектов и логикой.

## Основные сцены

### 1. DeveloperLevel
**Расположение**: `RogaliqueGame/Core/Levels/DeveloperLevel`

#### Ответственность:
- Управление игровым процессом
- Генерация лабиринта через `MazeGeneratorComponent`
- Создание и управление игроком и врагами
- Интеграция с HUD

#### Ключевые методы:
```cpp
void Start() override;       // Инициализация уровня
void Update() override;     // Обновление логики
void Stop() override;       // Очистка ресурсов
void CreateLevel();         // Генерация уровня
void UpdateEnemiesCount();  // Обновление счетчика врагов
```
# Особенности:
- Использует MazeGeneratorComponent для создания лабиринта
- Автоматически размещает игрока в стартовой точке лабиринта
- Управляет спавном врагов в специальных точках
- Интегрирован с системой статистики через UnitStatsComponent

## 2. MainMenuScene
**Расположение**: `RogaliqueGame/Scenes/MainMenuScene`

### Ответственность:
- Отображение главного меню
- Обработка переходов между состояниями игры
- Управление UI элементами меню

### Ключевые компоненты:
- `Canvas` - корневой контейнер UI
- `VerticalBox` - основной контейнер меню
- `Button` - кнопки меню
- `Image` - фоновое изображение

### Особенности:
- Динамическое создание кнопок через `CreateButton()`
- Поддержка различных состояний кнопок:
  - normal
  - hovered
  - pressed
- Переходы между сценами через `GameStateManager`

  ### 3. GameHUD (псевдо-сцена)
**Расположение**: `RogaliqueGame/Core/UI/GameHUD`

#### Почему не отдельная сцена?
HUD реализован как компонент, а не отдельная сцена, потому что:
1. Должен отображаться поверх игрового уровня
2. Тесно связан с игровой логикой (здоровье, патроны и т.д.)
3. Требует минимального управления состоянием
4. Должен реагировать на игровые события в реальном времени

#### Функционал:
- Отображение здоровья игрока
- Счетчик боеприпасов
- Количество оставшихся врагов
- Информация о текущем уровне
- Меню паузы

#### Особенности:
- Подписка на события (например, `HealthChangedEvent`)
- Динамическое обновление показателей
- Полупрозрачное меню паузы

## Жизненный цикл сцены

1. **`Start()`**  
   - Инициализация ресурсов  
   - Создание игровых объектов  
   - Настройка начального состояния  

2. **`Update(float deltaTime)`**  
   - Обработка игровой логики  
   - Вызывается каждый кадр  
   - Параметр `deltaTime` - время с последнего кадра  

3. **`HandleEvent(const sf::Event& event)`**  
   - Обработка пользовательского ввода  
   - Передача событий UI-элементам  

4. **`Stop()`**  
   - Очистка ресурсов  
   - Удаление игровых объектов  
   - Отписка от событий
