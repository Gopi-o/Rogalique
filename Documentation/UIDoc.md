# Система пользовательского интерфейса

## Базовый класс Widget

### Обзор
Базовый класс для всех UI-элементов. Наследуется от `Component`.

**Расположение**: `Components/UI/Widget.h`

### Основные возможности:
- Иерархическая система родитель-потомок
- Обработка событий ввода (мышь)
- Управление видимостью
- Позиционирование и трансформации
- Система событий (hover, click и т.д.)

### Состояния виджета:
```cpp
enum class EWidgetVisibility {
    Visible,  // Видим и интерактивен
    Hidden,   // Невидим, но сохраняет место
    Collapsed // Невидим и не занимает место
};
```


### Ключевые методы:

| Метод                        | Описание                         |
|------------------------------|----------------------------------|
| `AddChild()`/`RemoveChild()` | Управление иерархией             |
| `HandleEvent()`              | Обработка событий SFML           |
| `SetPosition()`/`SetSize()`  | Управление размещением           |
| `SetVisibility()`            | Контроль видимости               |
| `CalculateDesiredSize()`     | Расчет предпочтительного размера |

### События:

```cpp
std::function<void()> OnHovered;
std::function<void()> OnUnhovered;
std::function<void()> OnPressed;
std::function<void()> OnReleased;
```

## Элементы UI

### 1. TextBlock
**Назначение**: Отображение текста

**Особенности**:
- Поддержка различных шрифтов
- Настройка цвета и outline
- Гибкое выравнивание текста

**Пример использования**:
```cpp
auto text = CreateGameObject()->AddComponent<TextBlock>();
text->SetText("Hello World");
text->SetFont("Roboto-Bold");
text->SetFontSize(24);
```

### 2. Button
**Назначение**: Интерактивная кнопка

**Особенности**:
- 4 состояния (normal/hover/pressed/disabled)
- Поддержка текста и иконок
- Кастомизируемые обработчики событий

**Пример**:
```cpp
auto button = CreateGameObject()->AddComponent<Button>();
button->SetText("Start Game");
button->OnClick = []() { LoadLevel("Main"); };
```

### 3. Image

**Назначение**: Отображение статичных изображений

**Особенности**:
- Поддержка масштабирования
- Настройка origin точки
- Возможность поворота

## Система компоновки (Layouts)

### 1. VerticalBox
Автоматическое вертикальное размещение элементов с настраиваемыми:
- **Отступами (padding)**
- **Расстоянием между элементами (spacing)**
- **Автоматическим подбором размеров**

### 2. HorizontalBox
Горизонтальный аналог VerticalBox

### 3. Grid
Сеточная компоновка с настраиваемым количеством:
- Колонок
- Строк

  ## Canvas

### Назначение
Корневой контейнер для UI элементов.

**Особенности**:
- Управление порядком отрисовки (layers)
- Поддержка screen-space и world-space режимов
- Автоматическое обновение трансформ

### Пример создания UI-иерархии
```cpp
auto canvas = CreateGameObject()->AddComponent<Canvas>();

// Создаем вертикальный контейнер
auto panel = CreateGameObject()->AddComponent<VerticalBox>();
canvas->AddToLayer(panel);

// Добавляем элементы
auto title = panel->AddChild<TextBlock>()->SetText("Main Menu");
auto startBtn = panel->AddChild<Button>()->SetText("Start");
```

## Особенности реализации

### Обработка событий
- События обрабатываются от верхних слоев к нижним
- Если элемент "поглотил" событие (например, нажатие), обработка прекращается
- Поддержка каскадных событий (наведение/снятие)

### Система координат
- Все позиции относительны к родителю
- Методы `GetAbsolutePosition()` и `GetRelativePosition()` для конвертации

### Оптимизации
- Обновление трансформ только при изменениях
- Кэширование вычисленных размеров
- Пакетный рендеринг через `RenderSystem`
