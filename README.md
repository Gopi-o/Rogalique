# Описание проекта: Roguelike на C++ с SFML

## Краткое описание игры
Простой 2D roguelike с генерацией лабиринта, где игрок должен:
- Найти выход на следующий уровень
- Избегать врагов или уничтожить всех врагов
- Использовать HUD для отслеживания состояния
- Управлять игрой через меню (пауза, смена сцен)

## Структура проекта
### Движок (Engine) - основа на SFML для:
- Отрисовки графики
- Управления вводом
- Обработки сцен
- Базовой физики (коллизии)

### Игра (Game) - логика roguelike:
- Генерация лабиринта
- Спавн игрока, врагов, выхода
- Система уровней
- Простой HUD

## Запуск проекта
### Требования:
- C++17

## Как запустить:
### Шаг 1:
- Запустить файл Build.bat
### Шаг 2:
- Перейти по пути RogaliqueGame/x64/Release/
### Шаг 3:
- Открыть RogaliqueGame.exe
### Шаг 4:
- Наслаждаться игрой).

## Управление:
- WASD/Стрелки - движение
- Space(пробел) - атака
- ESC - пауза
